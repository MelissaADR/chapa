# Chapa Azul

Site da Chapa Azul para apresentar propostas, responsáveis, eventos,
campeonatos, calendário, times, participação das turmas e opiniões dos alunos.

## Desenvolvimento

Requer Node.js 22 ou superior.

```bash
npm install
npm run dev
```

## Verificação

```bash
npm run lint
npm test
```
